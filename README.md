# Bike Sales Analysis Dashboard (Microsoft Excel)

## Project Overview
This project analyzes customer purchasing behavior using a bike sales dataset to identify the key factors influencing bike purchases. The analysis was performed entirely in Microsoft Excel, following a structured data analysis workflow from data cleaning to dashboard creation.
The final outcome is an interactive dashboard that enables users to explore customer purchasing patterns across different demographic and geographic segments.

---

## Project Objectives
The primary objectives of this project were to:

- Clean and prepare raw customer data for analysis.
- Perform exploratory data analysis (EDA).
- Build KPI metrics for business reporting.
- Create PivotTables and PivotCharts to answer business questions.
- Design an interactive Excel dashboard using slicers.
- Generate actionable business insights.

---

## Business Questions
This project answers the following questions:

1. Does marital status influence bike purchases?
2. Which gender purchases the most bikes?
3. Does customer income affect bike purchases?
4. Which region has the highest number of bike purchases?
5. How does commute distance influence bike purchases?
6. Which age group purchases the most bikes?
7. Which occupation has the highest bike purchase rate?

## Key Business Insights

- Middle-aged customers represent the largest group of bike purchasers.
- Single customers purchase bikes more frequently than married customers.
- Customers in the North America region have the highest bike purchase rate.
- Professionals show the highest bike purchase rate among occupation groups.
- Customers commuting between 2–5 miles are more likely to purchase bikes.
- Income has only a modest influence on bike purchasing behaviour.
