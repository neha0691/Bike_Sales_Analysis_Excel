# Bike_Sales_Analysis_Excel
Interactive Bike Sales Analysis Dashboard built in Microsoft Excel using PivotTables, PivotCharts, KPIs and business insights.

# Project Overview:
This project analyses customer purchasing behaviour using a bike sales dataset. The objective was to identify the factors that influence bike purchases and present the findings through an interactive Microsoft Excel dashboard.
The project demonstrates the complete data analysis workflow, from data cleaning and feature engineering to dashboard creation and business insights.

# Business Questions:
Does marital status influence bike purchases?
Which gender has the highest bike purchase rate?
Does customer income affect bike purchases?
Which region has the highest number of bike purchases?
How does commute distance influence bike purchases?
Which age group purchases the most bikes?
Which occupation has the highest bike purchase rate?
